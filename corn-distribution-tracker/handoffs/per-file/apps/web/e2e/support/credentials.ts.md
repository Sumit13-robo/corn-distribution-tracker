# File Handoff: `apps/web/e2e/support/credentials.ts`

**Status:** TESTED
**Primary owner:** QA
**File purpose:** Per-run E2E credential reader

## Responsibility
Read the admin/distributor credentials generated by global setup from the gitignored `e2e/.state/credentials.json`, validate the identities, and fail with an actionable message when the suite is not started through the configured runner.

## Contract and dependencies
`global-setup.ts` writer; `config.ts` test identities; Playwright test bodies (the file is read lazily so test modules can load before global setup runs).

## Implementation summary
Caches the parsed credentials per worker process. No password is committed, displayed, logged or persisted outside the ignored state directory.

**Verification (2026-10-23):** used by both setup and workflow specs; 8 E2E tests passed with newly generated credentials.

**Unresolved issues:** `e2e/.state/` must remain gitignored; the suite recreates it on every run.
